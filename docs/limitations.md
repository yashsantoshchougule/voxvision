# Known limitations

- Web Speech API availability and behavior varies by browser and device.
- Microphone transcription may not capture every remote attendee; VoxVision does not claim otherwise.
- Tab-audio sharing needs explicit permission and browser support.
- OCR depends on readable, sufficiently large screen text.
- Chart observations are basic and never invent missing values.
- The MVP has no speaker identification or audio/screen timestamp synchronization.
- Google Meet is the only supported platform.
- Long meetings are size-limited and AI providers can impose costs or rate limits.
- Generated reports need user review before external use.
